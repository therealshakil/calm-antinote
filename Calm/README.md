# Calm

Warm paper-and-ink themes for Antinote — a light (**Calm Paper**) and a dark (**Calm Ink**).

Monochrome by design: warm off-white ground, near-black ink, and a single clay accent — no second
colour. Built to match a calm terminal palette, so a note sits beside your terminal as one surface.

- `calm-paper.json` — light
- `calm-ink.json` — dark

by [@shakilclark](https://github.com/shakilclark)
